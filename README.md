# 🧘 Yoga Website

A modern, responsive, and visually appealing Yoga website designed to promote a healthy lifestyle through yoga. The website provides information about yoga sessions, trainers, benefits, testimonials, and contact details while delivering a smooth user experience across all devices.

## 🌐 Live Demo

🔗 https://hasini-1.github.io/Yoga-Website/

---

## 📌 Features

- ✅ Modern and responsive design
- ✅ Smooth scrolling navigation
- ✅ Attractive landing page
- ✅ About Yoga section
- ✅ Benefits of Yoga
- ✅ Yoga Classes section
- ✅ Professional Trainers section
- ✅ Testimonials
- ✅ Contact section
- ✅ Clean and user-friendly interface
- ✅ Mobile, Tablet, and Desktop responsive

---

## 🛠️ Technologies Used

- HTML5
- CSS3

- Responsive Web Design
